# 추가 후보 검색 중단 — 기존 공통 장면 유지

공통 (0.44,−0.60)m 장면은 앞선 초기 입력의 지형·우회 검사를 통과했지만, 후속 실제 시험은 출발 후 최종 생성 검사에서 실패했다. 이 실제 실패를 기존 오프라인 VALID로 덮지 않는다. 원래 공통 장면 JSON과 앞선 감사 결과는 변경하지 않았다.

초기 선택 시점보다 10cm 이상 출발한 뒤 초기 후보의 60cm 최소 중심 거리를 다시 요구하면, 후보가 여전히 전방에 있고 경로를 실제로 막아도 최종 150ms 갱신 중 경계값을 지날 수 있다. 이 단계 구분 문제는 상자를 계속 옮겨 회피하는 대신 별도 생성 시점 증거로 검토한다. 이 문서와 JSON은 그 정책 수정을 구현하거나 검증한 자료가 아니다.

같은 실제 두 초기 fixture로 추가 후보를 검사했다. 모든 기존 선택 함수의 차체22cm·정적5셀·관측35cm·현재 우회·5개 상자 위치 검사는 유지했다.

| 오프라인 검색 범위 | 검사 수 | 양쪽 초기 입력 VALID | 결과 |
|---|---:|---:|---|
| x 0.46~0.56m, y −0.72~−0.62m의 1cm 격자 중 초기 HOME 거리 ≥0.80m, 기존 이동 방향 −1 | 99 | 0 | 현재 우회 폐쇄54 / 이후 이동 위치의 우회 미증명45 |
