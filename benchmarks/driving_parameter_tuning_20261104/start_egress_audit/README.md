# 장애물 제거 후 기억 15→0 수신과 출발 셀 감사

**결론:** `22cm` 차체가 실제 raw 셀과 겹친 사례는 아니지만, 기존 한 셀 출발 예외로도 해결할 수 없습니다. 확인된 빈 기억 메시지의 처리와 대기 재개가 우선입니다. 이 감사로 기억 셀·팽창·물리 여유를 삭제하거나 완화하지 않았습니다.

대상은 `/tmp/classroom-policy-replaced-baseline-20261104/25_web_inventory_sector3_moving_obstacle`의 두 번째 NoPath입니다. 실제 웹 재고 요청·pre-arm을 거친 Gazebo 시험이며, 이 오프라인 감사는 주행 성공 판정이 아닙니다. 이전 `recovery_audit/`의 합성 후진 이력 사례와 구분합니다.

## 기록과 실제 계획 입력

| wall epoch | 기록 |
| --- | --- |
| 1793802776.910987 | 시험 상자 제거 |
| 1793802778.716829 | 독립 기억 관찰기: 16셀 |
| 1793802779.362891 | 독립 관측 관찰기: 5셀 |
| 1793802779.377984 | 독립 기억 관찰기: **0셀** |
| 1793802779.379157 | planner: `(39,88)` 자유 광선 확인 후 복구 재개 |
| 1793802779.574723 | planner: **기억 15셀**, 관측 5셀로 NoPath |

계획 중 기억 15셀은 직전 16셀에서 원래 추적하던 `(39,88)` 하나를 뺀 값으로 재구성됩니다. 마지막 global 경로 65점으로 미관측 깊이도 재현하면 다음 런타임 수치와 **모두 정확히 일치**합니다.

| 항목 | 재현·로그 셀 수 |
| --- | ---: |
| 관측 원본 / 기억 원본 | 5 / 15 |
| 관측 팽창 / 기억 팽창 | 133 / 284 |
| 합친 보수적 동적 영역 | 393 |
| 실측만 사용한 동적 영역 | 344 |
| 미관측 가상 영역만의 차이 | 49 |

독립 관찰기의 기억 0과 planner의 15는 동일한 원자적 snapshot이 아닙니다. 긴 visibility 콜백 안의 local/reverse/global 계산과 다른 subscription의 처리 순서에 따른 지연과 일치하는 기록입니다. 정확한 planner subscription 진입 시각은 기록되지 않았으므로 queue 도착 순서를 추가로 단정하지 않습니다.

대기를 시작시킨 원래 셀 `(39,88)`은 이미 제거됐습니다. 반면 당시 출발 셀의 기억 팽창을 직접 만든 셀은 `(39,89)`, `(40,88)`, `(40,89)`, `(41,89)`입니다. 나중의 **관련 기억 15→0 삭제**를 원래 셀과의 교집합만으로 판정하면 실제 경로 조건이 좋아져도 대기를 깨우지 못합니다. 같은 빈 상태를 반복 발행했을 때 복구를 반복 실행하지 않는 조건도 함께 유지해야 합니다.

## 연속 차체와 격자 검사

자세는 `(0.152285944, -1.047901176, -0.810134643)`이며 출발 셀은 `(36,84)`입니다. 모든 raw 점유·unknown·관측·기억 셀의 **사각형 전체** 및 지도 경계에 대한 연속 거리를 검사했습니다.

| 검사 | 결과 |
| --- | ---: |
| 현재 연속 자세의 최소 중심 거리 | 27.9742cm |
| 22cm 원형 차체를 제외한 실제 셀 여유 | 5.9742cm |
| 출발 셀 중심의 최소 거리 | 24.7487cm |
| 기존 halo의 격자 양자화 포함 요구 거리 | 25.5355cm |
| 바로 인접한 8셀 중 팽창 밖 셀 | 0개 |
| 기존 `certified_start_only_edges` 허용 간선 | 0개 |

즉 차체의 실제 자세는 비어 있지만, 셀 중심을 기준으로 한 halo 검사는 거부합니다. 그러나 단순히 기억 팽창 gate를 빼도 모든 인접 셀이 계속 막혀 있어, **현재 한 셀만 예외로 하는 기존 helper는 탈출 간선을 만들지 못합니다.** 대각·전방 일부 인접점에는 실제 차체가 겹치는 경우도 있으므로 모든 이웃을 허용해서는 안 됩니다.

비교용 연속 prefix를 검사하면 `(33,84)`까지 약 12.93cm의 선분은 모든 실제 raw 셀을 유지한 채 중심 거리 27.9742cm를 확보하고 보수적 팽창 밖에서 끝납니다. 이 점에서 hard 가상 영역을 모두 유지한 목표 경로는 여전히 없으며, 기존 정책처럼 **가상 깊이만 비용으로 취급한** 실측 hard 경로는 존재합니다. prefix와 그 경로 전체의 연속 차체 여유는 최소 5.5cm입니다. 이는 오프라인 기하 비교이며 새 전진 예외의 승인이나 실행 증거가 아닙니다.

생산자가 확인한 **기억 0셀**을 실제 계획 입력으로 사용하면 기존 A*가 별도 출발 예외 없이 64셀 경로를 만듭니다. raw 정적·unknown·관측 셀은 그대로 유지하며, 현재 연속 자세부터 전체 경로까지 최소 차체 여유는 5.5cm입니다. 따라서 이 기록은 출발 팽창 정책을 바꾸기 전에 기억 삭제 수신·대기 재개를 고쳐야 한다는 근거입니다.
