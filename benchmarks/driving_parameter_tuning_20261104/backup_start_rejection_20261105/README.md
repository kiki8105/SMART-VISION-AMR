# 2.5cm 실시간 시험의 첫 후진 거부

이 시험은 local costmap 해상도만 5cm에서 2.5cm로 바꾼 전체 웹 시험입니다. Sector 3과 홈 복귀는 완료했지만 장애물 이동·우회 조건은 불합격이며, 2.5cm 값을 공식 설정으로 채택하지 않았습니다.

첫 `NO_SAFE_EGRESS`를 실제 관측 24셀·기억 11셀·보수 장애물 마스크 422셀과 동일하게 재생했습니다.

| 항목 | 기록값 |
|---|---:|
| 실제 source 이력 | 23점 |
| 현재 raw 사각형까지 거리 | 0.210681m |
| 차체 반경 | 0.220m |
| 인계·표본 여유 포함 요구값 | 0.235m |
| 목적지 확인 함수 호출 | 0회 |

| 검사 순서·입력 | 실제 첫 시험의 결과 |
|---|---|
| probe 시각 | 시작 후 32.1933s, source clock 18.900s |
| 현재 pose·source | (0.089319, -0.745954, -1.487752rad); odom/TF 18.896s, raw scan 18.799s |
| 입력 신선도 | odom source 4ms, scan source 101ms, scan receipt 약 215ms; `OK` |
| 현재 위치 raw 여유 | 210.681mm < 요구 235mm → 여기서 즉시 거부 |
| history/yaw/최소 이득 조건 | 첫 반환 뒤의 검사이므로 이 사례 원인으로 채택하지 않음 |
| 독립 현재축 끝점 검사 | 0.10~0.30m의 11개 후보 모두 전체 팽창 내부; 목적지 검색 호출 0회 |

첫 거부는 **현재 위치의 전체 raw 사각형 여유 부족**입니다. 과거 이력 경로·헤딩·단조 증가·최소 이득을 검사하기 전에 종료됩니다. 따라서 이 사례에서 해당 휴리스틱만 제거해도 결과는 달라지지 않습니다.

가장 가까운 셀 `(39,90)`은 관측과 기억 양쪽에 있고, 영역은 `[0.30,0.35] × [-0.75,-0.70]m`입니다. 선택된 22cm 원과 약 9.3mm 겹칩니다. 현재 후진축을 따라 10~30cm 뒤로 간 11개 끝점도 모두 기존 전체 팽창 영역 안에 있습니다. 이를 강제로 허용하지 않았습니다.

별도 소유 경로·추종 분석에서는 우회 경로에서 장애물 쪽으로 추정 차량 위치가 약 11.2cm, 실제 차량 위치가 약 14.5cm 벗어났습니다. 여기서 11.2cm는 AMCL 공분산이 아니라 경로 중심선과 추정 차량 위치 사이의 거리입니다. 안전한 우회선을 생성하는 것뿐 아니라 그 선을 따라가는 성능을 확인해야 합니다.

## 재현

ROS나 Gazebo를 실행하지 않습니다.

```bash
python3 benchmarks/driving_parameter_tuning_20261104/backup_start_rejection_20261105/replay.py \
  --output /tmp/first-backup-refusal.json
```

`fixture.json`에 실제 관측·기억 메시지와 원래 참조 경로, source 이력, 생성된 장애물 마스크를 보존했습니다. `results.json`에 실제 첫 반환 위치·입력 해시·목적지 확인 호출 수를 기록합니다. source 기록의 시각과 full-cell 장애물은 완화하지 않습니다.
