# 복구 정책 교체 검증

`closed_loop_v2.json`은 기존 집계 도구의 결과이며, `independent_v2_audit.json`은 같은 실제 기록을 별도로 확인한 자료입니다. 독립 감사는 기록 파일만 읽었으며 실행 중인 노드·서비스·웹·실차를 조작하지 않았습니다.

| v2 실제 전체 웹 시험 | 결과 |
|---|---|
| 재고 요청 → 실제 운용과 같은 pre-arm | 통과 |
| Sector 3·후방 마커 확인·5초 대기·Home 복귀·정지 | 통과 |
| 움직이는 상자 | 4회 중 2회 이동, 제거 전 우회 미완료 |
| 전체 판정 | **실패** — 목적지 완주와 장애물 우회 합격을 구분 |
| 역진 | 10.79cm 요청·BackUp 수락, 첫 충돌 검사에서 중단. 실제 음수 속도 출력 0회 |
| 장애물 제거 후 재개 | 기억 11셀→0셀 확인 후 0.189초에 경로 재개, 0.283초에 실제 속도 출력 |
| 상자와 차체 간 최소 간격 | 관측 5.795cm. 별도 truth·상자 위치 재계산도 약 5.794cm |
| 최종 Home 실제 오차 | 약 18.8cm, 기존 truth 허용치 25cm 이내. 지도 추정 오차는 14.7cm |
| 실행 소스 | 시험 전후 213개 기록 해시 동일 |

FollowPath 취소 완료 → 정지 확인 → BackUp → 해당 BackUp 실패 완료 → 전체 재계획 순서를 실제 로그에서 확인했습니다. 역진 후보 생성·액션 수락은 실제 후진 성공을 뜻하지 않습니다. `Collision Ahead`의 세부 원인은 별도 costmap·footprint 재현으로 분석하며 충돌 기준을 완화하지 않았습니다.

독립 JSON에는 입력 9개 파일의 SHA-256, 실제 이벤트 시각·goal/episode 식별자, 제거 후 기억 해제·재개 시각, truth와 지도 위치의 차이, 기록의 한계를 보존했습니다. 단일 Gazebo 시험 결과이며 실차 재검증이나 보편적인 최적 성능을 입증한 결과가 아닙니다.

## 변경 경로 진입 방향 정렬을 추가한 후

`independent_material_heading_audit.json`은 이후 같은 고정 장애물 장면의 실제 전체 웹 시험을 보존합니다. 실행 소스 해시 비교에서 follower만 바뀌었으며, 기존 실차 YAML·차체22cm·국소 costmap5cm·상자 QA는 유지했습니다.

| 실제 관측 | v2 이전 | 방향 정렬 추가 후 첫 시험 |
|---|---:|---:|
| 전체 판정 | 실패 | **통과** |
| 상자 이동·제거 전 우회 | 2/4·미완료 | 4/4·완료 |
| 최소 실제 상자 간격 | 5.79cm | 11.01cm |
| 임무·Home 정지까지 | 163.422초 | 114.838초 |
| 실제 역진 | 0회 | 0회 |

교체 경로를 받았을 때 FollowPath 취소 완료 후 실제 제자리 선회가 발생했습니다. 선회 중 속도 표본69개 모두 전진0, 최대 회전0.35rad/s였고 truth상 이동1.46mm·회전48°를 확인했습니다. 이 선회는 더 새 경로가 도착해 취소되었으므로 요청한 전체 회전량을 완료했다고 해석하지 않습니다.

Sector3·Home truth와 정지 검증도 통과했습니다. Home 실제 오차는 약19.8cm로 기존25cm 허용치 이내이며, 실차 재시험·정밀 도킹·후진 성공은 이 결과로 입증하지 않습니다. 첫 단일 시험의 개선이며 반복 검증 결과는 별도로 판단합니다. 새 분석기는 WAIT_CANCEL·정렬 대기·Spin에서 이전 경로의 실행 구간을 끝내야 하며, 다음 ACK 전 선회 궤적을 이전 경로 추종 오차로 집계해서는 안 됩니다.
