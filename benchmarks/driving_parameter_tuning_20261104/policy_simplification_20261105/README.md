# 주행 정책 단순화 — 2026-11-05

실제 1→2→3 뒤 Home 복귀 정체를 재현한 뒤, 실행 실패가 실제 점유 장애물처럼 경로를 막던 정책과 중복 출발 검사를 제거했습니다.

| 이전 결정 | 현재 결정 |
|---|---|
| 실행 실패 접근을 hard 금지하고 나중 scan 분류로 예외 허가 | 실행 실패는 처음부터 bounded 방향성 비용. 실제 점유 셀만 hard |
| 과거 segment·분류용 TF가 없으면 새 출발 차단 | 과거 진단 메타데이터는 출발 허가 조건이 아님. 현재 공통 입력 검사 유지 |
| planner와 follower가 다른 lookahead로 회전 가능 여부 판단 | planner는 경로 충돌, follower/Nav2는 실제 정렬·기동 담당 |
| 같은 목적의 초기 정렬 카운터·완료 상태 중복 | 실제 dispatch 참조와 단일 starts 예산 사용 |
| 생산 호출자가 없는 hold-probe 대체 경로 | 미사용 분기와 상태 제거 |
| 이전 초기 위치 입력 실패가 현재 정상 회복 후에도 웹 차단 | 현재 지도·TF·센서·위치 신뢰도 검사가 모두 정상일 때만 경고로 표시 |

운용 흐름은 **추종 → 국소 우회 → 검증 후진 → 전체 재계획 → 막히면 대기**입니다. 비상정지·수동 우선, 최신 입력, 실제 충돌 검사, 액션 종결·정지 확인은 별도 공통 실행 조건으로 유지합니다. 후진이 불가능하면 실행하지 않고 전체 계획으로 넘어갑니다.

검증 기록은 [checks.json](checks.json), 독립 소스 리뷰는 [final_policy_source_review.json](../recovery_replacement_validation/final_policy_source_review.json)에 있습니다. 전체 Python 2,732개, ROS 2개 패키지 빌드, C++ ctest, 정적 설치 검사를 통과했습니다. 첫 전체 실행의 오래된 hard-memory 테스트 입력 1건은 실제 first-edge 인증을 제한하는 입력으로 고쳤으며, 차체 대각선 충돌 불변 조건과 원본 초기 검사 로그를 보존했습니다.

현재 설정의 실제 폐루프 결과는 별도로 기록합니다. 과거 material-heading 수정 직후의 이동 장애물 단일 PASS를 이 단순화 소스의 합격으로 이월하지 않습니다. 물리 로봇은 이번 작업에서 주행하지 않았습니다.
