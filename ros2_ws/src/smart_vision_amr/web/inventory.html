내 요청 내역

0건
아직 요청한 내역이 없습니다.
    접수 상태의 요청만 취소할 수 있습니다. 대기·운송 중 요청은 운용자에게 문의하세요.
    완료·취소 기록을 정리하고 차량의 홈 복귀를 요청합니다. 운행 중 기록은 홈 도착 확인 후 자동 정리하며 미완료 요청은 유지됩니다.

    이 페이지에서는 재고 요청과 내 배송 내역만 확인할 수 있습니다.

    배송 기록을 초기화하고 홈 복귀를 요청할까요?

    모든 관리자의 완료·취소 기록 중 0건을 즉시 삭제합니다. 현재 운행에 연결된 완료·취소 기록 0건은 안전한 홈 도착이 확인되면 자동 삭제합니다. 이미 홈이면 즉시 정리됩니다. 접수·대기 요청은 유지되며, 운송 중 미완료 요청은 홈 복귀 시 다시 대기합니다. 차량이 연결되지 않았거나 출발 조건을 충족하지 못하면 기록만 초기화되고 홈 복귀는 시작되지 않습니다.
