# 저장 지도에 없는 실제 장애물

실차 도메인 16의 `run_classroom_navigation_16.sh`는 저장한 강의실 지도와 실시간 `/scan`을 함께 사용한다. 이 스크립트의 기본 설정은 `memory_enabled:=true memory_persist_to_disk:=false`다. 실제로 관측해 확정한 장애물 셀은 **주행 프로세스가 실행되는 동안** 섹터 목표가 바뀌어도 기억하지만, PC 주행 프로세스를 종료하고 다시 켜면 비워진다. 기존 JSON 기억 파일도 읽거나 쓰지 않는다.

1. `change_memory`가 최신 LiDAR와 지도→센서 TF로 장애물 셀을 계산하여 `/smart_vision_amr/observed_obstacles`에 발행한다.
2. 확인 전 장애물은 실시간 관측층에 반영한다. 같은 지도 셀을 **5회 이상, 첫 관측부터 최소 2초** 동안 장애물로 확인하면 기억층에 추가한다. 최소 관측 간격은 0.25초다. 이후 시야에서 벗어나도 A*가 다음 섹터 경로를 계획할 때 이 셀을 장애물로 취급한다.
3. A*가 현재 경로와 겹치는 장애물을 발견하면 경로를 취소하고 같은 목표를 유지하며 국소 우회 또는 전체 재계획을 시도한다. 우회로가 없으면 정지한 채 재시도한다. 기억된 셀은 해당 위치를 통과하는 유효한 라이다 레이로 **5회 이상, 첫 빈 공간 관측부터 최소 2초** 확인해야 제거한다. 단순한 시야 이탈·스캔 손실·시간 경과는 삭제 근거가 아니다.
4. Nav2의 로컬 장애물·voxel 계층은 별도로 `/scan`을 받아 5Hz로 근거리 충돌 회피를 수행한다.

웹 운용지도의 원본·정리된 지도에는 **현재 라이다가 보는 셀을 빨간색**, 관측을 거쳐 확정해 기억한 셀을 **진한 빨간색**으로 구분해 표시한다. 이미 기억한 물체가 시야 밖으로 나가면 밝은 현재 관측 표시만 사라지고 진한 기억 표시는 남는다. 물체를 치운 뒤 해당 위치에 유효한 빈 공간 관측이 누적되면 기억 표시도 사라진다. 표시는 ROS의 임시 관측·기억 토픽을 반영하며 저장된 지도 파일을 고치지 않는다.

예를 들어 Sector 1로 가며 확인한 상자를 Sector 1 도착 후 볼 수 없더라도 Sector 2 경로 계획에는 기억한 상자가 반영된다. Sector 2로 가는 중 상자를 치웠을 때 로봇이 그 자리를 직접 다시 스캔해 비어 있음을 확인해야 기억이 해제된다. 기억 해제 자체가 무조건 즉시 새 경로를 만드는 것은 아니므로, 제거 뒤 기존 경로를 그대로 따르는지 재계획하는지는 경로와 계획 횟수를 함께 관찰한다.

확정 전 실시간 셀은 유효한 자유 공간 레이가 통과하면 즉시 해제한다. 모든 레이가 정상인 스캔에서는 잠시 가려진 셀을 최대 2초 동안 유지한다. 일부 레이가 잘못되거나 빠진 스캔에서는 기존 장애물을 시간 초과만으로 해제하지 않고, 유효한 자유 공간 관측을 기다린다. NaN, 측정 최소거리 미만, 오래된/중복 스캔 및 오래된 TF는 자유 공간의 증거로 쓰지 않는다. 도메인 16 설정에서는 관측 계층 갱신이 2초 동안 끊기면 A*가 주행 경로를 취소하고 같은 목표를 유지한 채 최신 관측을 기다린다.

다른 팀 차량이 지나가도 LiDAR에는 일시적인 미등록 장애물로 보인다. LiDAR만으로 그 물체가 차량인지 구별하지는 않는다. 짧게 지나간 차량은 확정 조건을 채우지 못하지만, 같은 셀에 오래 정차하면 이번 주행의 장애물로 기억될 수 있다. 해당 셀을 실제로 비어 있다고 재관측하면 해제한다. 통로가 막혀 3회 실패하면 목표를 유지하고 정지하며, 라이다가 막혔던 공간을 **연속 2초 동안 비어 있다고 실제로 확인한 뒤** 다시 계획한다. 차량이 단순히 시야에서 사라졌거나 센서가 끊긴 경우에는 출발하지 않는다. 실패한 접근의 임시 경로 페널티(`failure_memory_enabled`)는 물리 장애물 셀 기억(`memory_enabled`)과 별개이며 최대 120초 유지될 수 있다. 다른 팀 로봇과 ROS 토픽이 섞이지 않도록 각 팀의 `ROS_DOMAIN_ID`는 달라야 한다.

설정은 `ros2_ws/src/smart_vision_amr/config/classroom_hardware_nodes.yaml`에 있다.

- `/astar_planner.live_obstacle_layer_required`: 실시간 관측을 필수 조건으로 사용한다.
- `/astar_planner.live_obstacle_timeout`: 관측 중단 후 정지 판정 시간, 기본 2초.
- `/change_memory.live_obstacle_ttl_sec`: 정상 스캔에서 가려진 장애물의 임시 유지 시간, 기본 2초. 잘못된 레이는 장애물 해제 근거로 사용하지 않는다.
- `/change_memory.live_scan_max_age_sec`, `live_transform_max_age_sec`: 사용 가능한 스캔·TF의 최대 시각 차이, 기본 1초.
- `memory_enabled:=true memory_persist_to_disk:=false`: 실차 기본 실행에서 섹터 간 셀 기억을 사용하고 디스크 저장·복원을 끈다. 주행 프로세스를 재시작하면 이전 기억은 사라진다.
- `laser_filter_for_change_memory:=false`: 선택형 Speckle 필터는 기본으로 끈다. 실제 얇은 장애물을 지울 수 있어 단발 반사 원인 확인 없이 켜지 않는다. Nav2와 안전 정지는 원본 `/scan`을 사용한다.

저장된 SLAM PGM/YAML은 변경하지 않는다. 기존 정적 지도 인플레이션, 차체 반경, 속도 및 조향 튜닝도 유지한다. LiDAR 높이보다 낮거나 센서가 실제로 관측하지 못하는 장애물은 이 계층으로 검출할 수 없다.

한 주행 프로세스에서는 같은 지도를 사용해야 한다. 기억 셀 토픽은 지도 버전을 함께 싣지 않으므로, 실행 중 다른 지도 파일로 바꾸려면 주행 스택을 종료하고 새 지도로 다시 시작한다.
