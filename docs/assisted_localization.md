# 웹 라이다 위치 확인

최초 로봇 런타임 설치와 실행은 [실차 시작 안내](hardware_ekf.md)를 따릅니다. 새 구성은 시작 시 비상정지를 유지하므로 센서가 안정된 후 명시적으로 해제하고 아래 회전을 진행합니다. 위치 신뢰도 문제로 해제가 막히면 해제 창의 **실제 홈 확인 → 초기 위치만 입력**을 사용하거나 조종기에서 실제 위치를 지정합니다. 초기 위치 입력 자체는 정지 해제나 이동 명령이 아닙니다.

전원 재시작 후 **차량이 실제 등록 홈에 정지해 있다면** 운용 웹 지도 아래의
**자세 초기화**를 누를 수 있다. 후방 ArUco 0번이 보이면 홈 판단에 참고하지만,
카메라가 끊겨도 LiDAR 위치 확인 자체는 허용한다. 후방 카메라에 다른 번호의
마커가 선명하게 보이면 홈 가정이 모순되므로 버튼을 거부한다. 차량이 홈이
아니거나 홈 여부가 불확실하면 **일반 위치 확인**을 사용한다.

자세 초기화는 등록 홈 좌표와 방향을 AMCL의 초기 **가설**로 발행한 후,
기존의 주행 취소·mux 정지 확인·30cm 회전 여유 검사·저속 회전·LiDAR/저장 지도
일치도 및 AMCL 안정성 검사를 그대로 거친다. 홈 좌표를 넣었다는 사실만으로
위치 추정 성공으로 표시하지 않는다. 결과가 실제 지도상의 위치·방향과
다르면 임무를 시작하지 말고 재확인한다. 성공해도 자동 출발하지 않는다.

실차 도메인 16에서 로봇의 `~/SMART-VISION-AMR/scripts/robot_bringup_camera_16.sh`와 PC의
`./scripts/run_classroom_navigation_16.sh`를 같은 EKF 모드로 실행한 뒤
운용자 웹 지도 아래 **위치 확인**을 누른다. 유효한 현재 위치가 있으면 기존 AMCL
분포를 유지하며 보정한다. 위치가 없거나 무효화된 경우에는 `/initialpose` 입력 없이도
AMCL 전역 위치 추정 서비스를 이용해 지도 전체에서 위치 후보를 찾는다.
선택한 저장 지도와 실제 `/map`이 일치하고, AMCL이 활성 상태이며,
360도 LiDAR와 odom 및 속도 우선순위 노드가 연결되어 있어야 한다.

1. 기존 임무의 목표·순서·완료 기록을 보존하고 주행을 일시정지한다.
2. 주행 취소 확인, 실제 정지, 속도 mux의 제어권 확인 후 위치를 보정한다.
   유효한 기존 위치가 없는 경우에만 AMCL 전역 재초기화를 요청한다.
3. 전진 없이 `0.20 rad/s`로 최대 한 바퀴 회전한다. 회전량은 명령 시간이 아닌
   실제 odom의 방향 변화로 측정한다. 회전 중 정지 상태 갱신 서비스도 호출한다.
4. 최신 AMCL 위치의 표준편차가 위치 `0.25m`, 방향 `0.26rad` 이하이며,
   LiDAR 끝점의 90% 이상이 지도 벽과 15cm 이내로 일치하고 중간 광선이
   다른 벽이나 미지 영역을 통과하지 않으며,
   최소 90도 회전 및 여러 갱신의 안정성이 확인되면 멈춘다.
5. 정지 후 새 AMCL 갱신까지 확인해 **위치 추정 완료**로 표시한다.
   기존 임무는 자동 재개하지 않는다. 지도상 위치·방향을 확인하고 재개한다.

총 제한 시간은 65초다. 버튼 옆에 누적 회전량과 추정 오차를 표시한다.
**회전 중지**, 일시정지, 비상정지로 중단할 수 있다. 조이스틱 개입이 가장 우선하며
진행 중인 위치 확인을 종료한 뒤 조종권을 가져온다.
센서·AMCL·속도 제어 연결 단절, 지도 불일치, odom 점프, 회전 공간 부족 시 정지한다.
라이다 누락은 즉시 정지하고 최대 1초 복구 대기하며, 근접 장애물과 오래된 센서는
즉시 중단한다. 기존 위치 보정 모드의 실패·취소는 기존 AMCL 위치를 무효화하지 않는다.
지도 전체 탐색에 실패한 경우에는 재시도하거나 수동 초기 위치를 지정하고 최신 지도
일치를 확인해야 자동 임무를 재개할 수 있다.

회전 공간은 차체 중심 기준 반경 30cm로 검사하며 실제 LiDAR 장착 오프셋도 반영한다.
실물 LDS의 물체 경계에서 생기는 고립된 0/NaN 측정은 전체의 2% 이하이고
양옆 측정의 각도 간격이 2도 이하이며 두 이웃에 추가 8cm 여유가 있을 때만
보수적으로 보완한다. 연속된 누락이나 근접 측정은 회전을 허용하지 않는다.
센서 높이 아래 장애물은 이 검사로 보이지 않으므로 주변 공간을 먼저 확보한다.
대칭적인 복도·방에서는 LiDAR만으로 위치를 구분하기 어려울 수 있다. 이 기능은
확률적 위치 **추정**이며, 임의의 환경에서 절대 위치를 보장하지 않는다.

AMCL 서비스 이름과 초기 좌표 없는 전역 재추정 동작은
[Nav2 Humble AMCL 구현](https://api.nav2.org/nav2-humble/html/amcl__node_8cpp_source.html)을 따른다.
`/reinitialize_global_localization`, `/request_nomotion_update`는 `std_srvs/srv/Empty`다.

## 검증

단위·HTTP·ROS 어댑터 및 회귀 테스트와 별개로, 격리된 Gazebo 도메인 220에서
실제 라이다·odom·AMCL·mux를 사용해 버튼 API를 시험했다.
강화된 지도 일치 검사에서 약 310도 회전 후 실제 시뮬레이션 위치와 약 3cm 차이로
수렴했고, 자동 출발 없이 정지했다. 이는 실차 정확도를 보장하는 수치가 아니다.
재현 스크립트는 `scripts/verify_gazebo_localization.py`, 기록은
`docs/gazebo_localization_e2e_20261027.json`이다. 실제 도메인 16에는 시험 주행 명령을 보내지 않았다.

실시간 추가 장애물 처리는 [별도 안내](live_obstacle_avoidance.md)를 참고한다.
