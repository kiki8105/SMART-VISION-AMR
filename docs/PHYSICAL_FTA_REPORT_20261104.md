## 1. 분석 목적 및 범위

본 보고서는 **11월 4일 실차에서 자율 진행이 중단되거나 정체돼 운용자 개입 또는 시험 중단으로 이어진 사례**를 고장수목으로 분석한다.

당일에는 Sector 2 배송 및 Home 복귀 기록도 존재했다. 따라서 “11월 4일 모든 임무가 실패했다”는 전제를 두지 않는다. 정상 수행 구간과 문제가 발생한 구간을 분리한다.

분석 범위는 운용자의 출발 요청부터 위치·입력 확인, 경로 생성, 추종·정렬 및 Home 복귀까지다. 계획된 인수 대기, 정상적인 운용자 일시정지, 예정된 종료는 실패에 포함하지 않는다.

**유효하지 않은 입력에 대한 안전정지 자체를 장치 고장으로 분류하지 않는다.** 그 상태가 해당 관찰 구간에서 해소되지 않아 자율 임무를 이어가지 못한 경우를 상위 운용 실패와 연결한다.

### 1.1 분석 원칙

FTA는 상위의 원치 않는 사건을 정의한 후 그 사건을 일으킬 수 있는 조건을 논리 게이트로 전개하는 하향식 분석이다. 본 보고서는 OR를 대체 발생 경로, AND를 함께 성립해야 하는 조건으로 사용한다. 방법론은 [NASA Fault Tree Handbook with Aerospace Applications, Version 1.1, 2002, Chapters 3·4·6](https://s3vi.ndc.nasa.gov/ssri-kb/static/resources/Fault%20Tree%20Handbook_NASA.pdf)을 참고했다.

- 서로 다른 실차 시험에서 나온 사실을 하나의 동시 발생 사건처럼 AND로 묶지 않는다.
- 사건 발생 확률과 임무별 노출 횟수가 없어 고장 확률·실패율·정량 중요도는 산출하지 않는다.
- 정상 재시도로 회복할 수 있는 NoPath 1회나 취소 1회를 곧바로 임무 실패로 판단하지 않는다.
- 재생 시험은 특정 실차 입력의 작동 기제를 검토하는 근거이며 실차 재시험과 구분한다.

### 1.2 근거 수준

| 표기 | 의미 |
|---|---|
| O | 보존된 실차 로그·상태값에서 관찰한 사실 |
| S | 당시 사용자 보고 또는 기존 실차 분석 문서의 요약. 전체 원시 시계열은 미확보 |
| R | 11월 4일 실차 입력을 이용한 고정 입력 재생에서 확인한 작동 기제 |
| U | 세부 원인이 미전개됐거나 추가 증거가 필요한 사건 |

O는 관찰 상태가 확인됐다는 뜻이며, 그 상태를 만든 모든 근본 원인이 확정됐다는 뜻은 아니다.

## 2. 최상위 사건 정의

### TE-01 — 실차 자율 임무 진행의 회복 실패

> 2026년 11월 4일 실차 운용에서 출발·주행·복귀 진행이 중단 또는 정체되고, 운용자 개입이나 시험 종료 이전까지 정상적인 자율 진행이 회복되지 않은 상태.

일시적인 감속이나 짧은 정지가 모두 TE-01에 해당하는 것은 아니다. 또한 운용자가 개입했다는 사실만으로 이후 자동 복구가 영구적으로 불가능했다고 단정하지 않는다.

분석 관찰 구간의 종료는 **운용자 수동 개입 또는 해당 시험 종료 시점**으로 한정한다. 당시 기록만으로 새 임의 시간 기준을 설정하지 않는다.

## 4. 상위 고장수목

시스템 구성과 정상 승인 조건을 함께 비교하려면 [기존·현재 시스템 블록 및 논리 비교도](SYSTEM_BLOCK_LOGIC_COMPARISON_20261105.md)를 참고한다. 승인 논리는 고장수목의 보수와 임무 성공을 동일시하지 않는다.

아래 수목은 기능 수준의 실패 경로다. 모든 사건은 **동일 관찰 구간 e** 안에서 평가한다. I·P·M(e)와 R(e)를 서로 다른 시험 사이에서 결합하지 않는다. 동일한 R-01은 해당 구간의 같은 사건을 재사용한 것이며, 별개로 독립 발생하는 세 고장으로 취급하지 않는다.

~~~mermaid
flowchart TD
    T["TE-01 실차 자율 임무 진행의 회복 실패"] --> G0{{"OR"}}
    G0 --> A["F-01 입력 유효성 문제 후 진행 회복 실패"]
    G0 --> B["F-02 경로 확보 실패 후 진행 회복 실패"]
    G0 --> C["F-03 추종·정렬 정체 후 진행 회복 실패"]
    G0 --> D["X-01 예정외 전원 중단으로 시험 지속 불가"]
    A --> GA{{"AND"}}
    GA --> I["I-01 유효 위치·시각 입력 미확보"]
    GA --> RA[["R-01 관찰 구간 내 자율 진행 미회복 / 미전개"]]

    GC --> M["M-01 부적절한 선회 또는 목표 근처 진행 부족"]
~~~

### 4.1 논리식

    F-01(e) = I-01(e) AND R-01(e)
    F-02(e) = P-01(e) AND R-01(e)
    F-03(e) = M-01(e) AND R-01(e)

    TE-01(e) = F-01(e) OR F-02(e) OR F-03(e) OR X-01(e)

R-01은 아직 특정 단일 코드 결함이나 부품 고장으로 분해하지 않은 **회복 기능 수준 사건**이다. 해당 구간에서 왜 회복되지 않았는지는 거부 사유·명령·이동 이력을 추가 확인해야 한다.

X-01은 시험 지속 의도가 있었던 전원 중단에만 성립하는 S·U 수준의 조건부 가지다. 보고된 중단의 예정외 여부와 원인은 미확정이며, 예정 종료는 포함하지 않는다. 주행 알고리즘 결함으로 분류하지 않는다.

### 5.2 P-01: 해당 계획 입력에서 경로 확보 실패

P-01 자체는 로그로 관찰됐지만, 모든 표본의 실제 통로 가능성과 지배 차단 계층은 확정하지 못했다. 따라서 아래 내용은 원인별 진단 분류이며 서로 독립적인 확정 기본 고장으로 간주하지 않는다.

| 진단 분류 | 11월 4일 근거 | FTA 판단 |
|---|---|---|
| 시작 위치의 격자·팽창 영역 차단 | static_start=True 8회 | 시작 셀 차단은 확인. 실제 차체·실측 공간과의 불일치 여부는 추가 비교 필요 |
| 실시간 관측·팽창 영향 | 관측 장애물 및 300개 이상 팽창 셀 기록 | 연결성 차단에 기여할 수 있으나 오검출·과도 팽창으로 확정하지 않음 |
| 실시간 관측 외 계층의 차단 | observed_raw=0인 NoPath 3회 | 실시간 장애물만으로 설명 불가. 정적 지도·위치·출발 연결 확인 필요 |
| 장애물 지속 기억 | 모든 대상 NoPath의 remembered_raw=0 | **이 기록에서 직접 차단 원인으로 채택하지 않음** |
| 실패 접근·실패 경로 제한 | 별도 분석 문서에 통로 제한 사례가 있으나 실차 원시 자료 연결이 불충분 | 장애물 지속 기억과 구분하고, 본 수목의 확정 원인에서 보류 |

**통로가 실제로 통과 가능했다는 독립 기하 증거가 없으면 “안전 경로 없음 판정이 잘못됐다”고 확정할 수 없다.** 반대로 NoPath가 나왔다는 사실만으로 실제 물리 통로가 없었다고 단정할 수도 없다.

경로가 없는 경우에도 재시도·국소 우회·검증된 후진으로 회복됐다면 해당 NoPath는 TE-01을 구성하지 않는다. F-02에는 R-01이 함께 필요하다.

| 확인한 기제 | 로컬 목표를 고르는 공간상 범위가 경로를 따라가는 진행 순서와 다를 수 있음 |
| 해석 | 특정 입력의 부적절한 선회 기제를 뒷받침. 모든 실차 선회의 공통 원인으로 일반화하지 않음 |

당시 실제 costmap 전체 이력은 보존되지 않아 라이다로 재구성했다. 따라서 이는 원래 실행의 모든 후보 점수를 완전히 재생한 증명이 아니라 **기록된 실차 입력에 기반한 기제 재현**이다.

#### 나. Home 접근 정체

기존 실차 분석에는 Home까지 약 0.16~0.17m, 방향 오차 약 135°가 남은 상태에서 속도 명령이 약 0.01m/s 이하로 작아지고 실제 이동이 거의 없던 사례가 기록돼 있다.

이는 목표 근처 제어·정렬의 진행 부족을 뒷받침한다. 그러나 바퀴 불감대, 바닥 마찰, 모터 전원 또는 로컬 제어 비용 중 어느 하나가 단독 원인이었는지는 해당 요약만으로 확정하지 않는다.

기록된 A* 계산 시간은 약 **10~22ms**다. 진행 실패 판정·재시도 대기와 A* 계산 시간을 구분해야 하며, 긴 정체를 전역 탐색 계산 자체의 병목으로 단정하지 않는다.

### 5.4 R-01: 회복 기능 미전개 사건

| 확인할 회복 단계 | 현재 근거와 한계 |
|---|---|
| 국소 우회 | 기능 존재와 별개로, 해당 정체 시 실제 후보·거부 이유를 연결할 기록 필요 |
| 후진 진입 | 보존된 대상 왕복 기록에서 새 후진 요청·실행 근거를 찾지 못함 |
| 후진 구동 | 요청 자체의 근거가 없으므로 “명령을 받았으나 모터가 후진하지 않음”으로 판정하지 않음 |
| 대체 경로·재개 | 취소 완료, 새 경로 승인, 최종 출력과 실제 이동을 같은 시각축에서 확인해야 함 |
| 운용자 개입 | 개입 이전까지 회복되지 않은 사실과 개입 이후의 이동을 분리해야 함 |

따라서 후진 관련 고장은 현재 **“회복 경로가 성립했는지 미확정”** 수준이며, “후진 하드웨어 고장”으로 발행하지 않는다.

### 5.5 X-01: 예정외 전원 중단

첫 복귀 시험 중 배터리 전원 중단이 보고돼 왕복 완료를 확인하지 못한 구간이 있다. 이 사건은 임무 지속을 막는 외부 운용 사건으로 포함한다.

보존된 자료만으로 잔량 부족, 부하 시 전압 강하, 접촉 불량 또는 운용자 전원 해제를 구분하지 못한다. 이를 모터·OpenCR 고장이나 특정 전압 기준의 부적절함으로 확정하지 않는다.

따라서 보고된 중단이 예정외였다고 확정하지 않는다. X-01은 임무를 계속하려던 구간에서의 중단에만 적용하며, 충전·점검을 위해 계획적으로 끝낸 운용은 제외한다.

## 6. 분석 수준 최소절단조합

이 표는 현재 미전개 사건을 말단으로 취급했을 때의 논리적 최소 조합이다. 완전 전개된 부품 수준 최소절단집합이나 발생 확률 순위가 아니다.

| 조합 ID | 조합 | 의미 |
|---|---|---|
| MC-01 | I-11 AND R-01 | TF 유효성 미확보와 해당 구간의 진행 미회복 |
| MC-02 | I-12 AND R-01 | footprint 시각의 odom 부재와 해당 구간의 진행 미회복 |
| MC-03 | P-01 AND R-01 | NoPath와 회복 경로 미성립 |
| MC-04 | J-01 AND J-02 AND R-01 | 접힌 경로·부적절한 로컬 목표 선택 기제·진행 미회복 |
| MC-05 | H-01 AND H-02 AND R-01 | 목표 근처 방향 오차·작은 명령과 이동·진행 미회복 |

## 7. Home 도착 상태의 증거 정정

이 항목은 **주 수목의 확정 실패 원인이 아니라 도착 검증 공백**으로 분리한다.

| 항목 | 원시 상태값 |
|---|---|
| 복귀 완료 이벤트 | 2026-11-04 13:04:03.415 KST |
| 위치 스냅샷 | 2026-11-04 13:06:32.276 KST |
| 시각 차이 | 약 148.862초 |
| 당시 활성 임무 Home | x=0.055565, y=-0.202145, yaw=0.026432rad |
| 등록 Home 기준값 | x=-0.188431, y=-0.220497, yaw=-0.027514rad |
| 이후 추정 위치와 활성 Home 차이 | 약 0.820399m, 150.585° |
| 이후 추정 위치와 등록 Home 차이 | 약 0.599120m, 147.494° |
| 이후 위치 상태 | critical, scan_map_disagreement |

기존 요약의 “등록 Home과 약 0.82m·151° 차이”라는 표현은 기준점을 혼동한 것이다. **0.82m·151°는 당시 활성 사용자 지정 Home과의 차이**로 정정한다.

또한 약 149초 뒤의 불량 위치 추정을 완료 순간의 실측 위치로 사용할 수 없다. 가능한 설명에는 완료 이후 이동, 이후 측위 변화 또는 완료 시점 정합 문제 등이 있으나 현재 자료로 선택할 수 없다.

따라서 “로봇이 잘못된 장소에서 완료를 선언했다”는 사건은 **미확정**이다. 다음에는 완료 시점의 활성 Home·TF·위치 신뢰도·실측 또는 영상 확인을 함께 저장해야 한다.

## 9. 조치 우선순위 및 종결 기준

우선순위는 정량 고장 확률이 아니라 **임무 진행 영향과 확인된 증거의 강도**를 기준으로 한 기술 판단이다. 아래는 후속 조치·검증 계획이며 보고서 작성 중 실행하지 않았다.

| 우선순위 | 대상 | 조치 방향 | 해당 가지의 종결에 필요한 증거 |
|---|---|---|---|
| P1 | I-11·I-12 | 센서 취득·수신·TF·odom 이력을 같은 시각축에서 추적하고 유효 입력 재취득 이후의 재개를 확인 | 같은 입력 문제 후 자동 복구·정상 출력·실제 진행까지 연결한 기록 |
| P1 | M-11 | 경로 순서에 따른 로컬 목표와 후보 평가를 확인 | 같은 접힌 배치에서 불필요 선회 감소 및 실제 경로 추종 확인 |

센서 손실·실제 충돌·후방 공간 부족을 무시하는 방식은 위 가지의 종결 증거가 아니다. 각각의 조건에서 임무가 어떻게 안전하게 회복되는지를 확인해야 한다.

## 10. 결론

11월 4일 실차 실패는 하나의 원인으로 확정할 수 없다. 보존 자료는 **입력 시각·위치 유효성 문제, 계획 입력의 경로 차단, 특정 접힌 경로의 로컬 목표 선택 기제, Home 근처 진행 부족, 그리고 전원 중단**을 서로 다른 실패 경로로 지지한다.

특히 NoPath나 정상적인 안전정지만으로 전체 임무 실패를 정의하면 원인 분석이 왜곡된다. 이번 FTA는 이들 사건에 **관찰 구간 내 자율 진행 미회복**이 함께 성립할 때 상위 운용 실패로 연결되도록 구성했다.

현재 근거로 확정할 수 없는 항목은 후진 모터 고장, 모든 장애물의 오검출, 지속 기억의 전면적 책임, 완료 시점의 오도착 및 11월 5일 고장의 소급 적용이다.

본 보고서는 **11월 4일 실차 실패를 대상으로 한 기능 수준 정성 FTA 발행본**이다. 전체 근본 원인의 종결이나 고장 확률 산출을 의미하지 않는다.
